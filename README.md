# 증여세 계산기

증여받은 금액을 입력하면 납부할 증여세를 **계산 과정과 함께** 보여주는 웹 계산기입니다.
1인 개발 학습 프로젝트로, 2주 단위 스프린트로 진행합니다.

> ⚠️ 계산 결과는 참고용 추정치입니다. 실제 신고·납부 세액과 다를 수 있으며,
> 정확한 세액은 세무 전문가 또는 관할 세무서에 확인하세요.

## 현재 상태

**Sprint 1** (2026-08-19 ~ 2026-09-01) 진행 중
지원 범위: 부모 → 성인 자녀 **현금** 증여 1케이스

## 구조

```
src/
  tax-rules.js       세법 숫자만 담는 단일 소스 (세율·공제·공제율)
  tax-calculator.js  계산 로직 (S-03)
tests/               브라우저 테스트 (S-04)
docs/
  S-01-research-note.md   세율·공제 조사 결과 + 출처
  issues/                 스프린트 백로그 (GitHub Issues 등록용)
scripts/
  create-issues.sh   gh CLI로 이슈 일괄 등록
```

## 설계 원칙

**세율·공제 숫자는 `src/tax-rules.js` 밖에 절대 쓰지 않는다.**
세법이 개정되면 그 파일 하나만 고치면 되도록 유지합니다.
