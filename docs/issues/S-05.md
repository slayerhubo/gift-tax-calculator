## 사용자 스토리

> **이용자**로서, 결과 숫자만이 아니라 **어떻게 그 숫자가 나왔는지** 보고 싶다.
> 그래야 결과를 믿을 수 있다.

## 완료 조건 (AC)

- [ ] 계산 단계를 표로 표시:
      `증여재산가액 → 증여재산공제 → 과세표준 → 적용 세율 → 산출세액 → 신고세액공제 → 납부할 세액`
- [ ] 최종 납부액을 시각적으로 가장 강조
- [ ] 모든 금액에 천 단위 콤마
- [ ] 신고기한 안내 문구: "증여일이 속하는 달의 말일부터 3개월 이내"
- [ ] 납부세액 0원인 경우 "납부할 증여세가 없습니다" 별도 표시
- [ ] 입력값 변경 시 즉시 재계산
- [ ] 모바일 360px에서 표가 깨지지 않을 것
