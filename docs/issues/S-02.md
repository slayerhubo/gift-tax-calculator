## 사용자 스토리

> **증여를 받은 일반인**으로서, 증여받은 금액을 입력하고 싶다.
> 그래야 계산을 시작할 수 있다.

## 완료 조건 (AC)

- [ ] 숫자만 입력 가능 (문자 입력 무시 또는 제거)
- [ ] 천 단위 콤마 자동 삽입 (`50000000` → `50,000,000`)
- [ ] 입력값 아래에 한글 단위로 실시간 표시 (`5,000만원`)
- [ ] 값이 비었거나 0 이하면 결과 대신 안내 문구 표시
- [ ] 모바일에서 숫자 키패드 노출 (`inputmode="numeric"`)
- [ ] 화면에 **"현재 부모→성인 자녀 현금 증여만 지원합니다"** 명시

## 참고

- 한글 단위 표시는 "0 하나 더 치는" 실수를 막기 위한 것. 실제 계산기에서 가장 흔한 사용자 오류다.
- 관계 선택 UI는 **이번 스프린트 범위 밖.** 직계존속→성년 직계비속으로 고정한다.
