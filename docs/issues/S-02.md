## 사용자 스토리

> **증여를 받은 일반인**으로서, 증여받은 금액을 입력하고 싶다.
> 그래야 계산을 시작할 수 있다.

## 완료 조건 (AC)

**화면 뼈대**

- [x] `index.html` 만들기 — 프로젝트의 첫 화면
- [x] `style.css` 만들기 — 기본 모양 (모바일 360px에서 안 깨질 것)

**입력 동작**

- [x] 숫자만 입력 가능 (문자 입력 무시 또는 제거)
- [x] 천 단위 콤마 자동 삽입 (`50000000` → `50,000,000`)
- [x] 입력값 아래에 한글 단위로 실시간 표시 (`5,000만원`)
- [x] 값이 비었거나 0 이하면 결과 대신 안내 문구 표시
- [x] 모바일에서 숫자 키패드 노출 (`inputmode="numeric"`)
- [x] 화면에 **"현재 부모→성인 자녀 현금 증여만 지원합니다"** 명시

## 참고

- **이 티켓이 프로젝트의 첫 웹페이지를 만든다.** 지금까지는 준비물(세율 데이터·문서)만 있고 화면이 없다.
- 한글 단위 표시는 "0 하나 더 치는" 실수를 막기 위한 것. 실제 계산기에서 가장 흔한 사용자 오류다.
- 관계 선택 UI는 **이번 스프린트 범위 밖.** 직계존속→성년 직계비속으로 고정한다.
- **계산은 이 티켓에서 하지 않는다.** 숫자를 받아서 보기 좋게 표시하는 데까지가 끝. 계산은 #3, 결과 표시는 #5.
