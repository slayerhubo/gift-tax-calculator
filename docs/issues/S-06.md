## 사용자 스토리

> **운영자**로서, 이 계산이 참고용임을 명확히 고지해야 한다.
> 그래야 이용자의 오해와 법적 리스크를 줄일 수 있다.

## 완료 조건 (AC)

- [ ] 결과 영역 **바로 아래**(스크롤 없이 보이는 위치) + 푸터에 면책 문구 노출
- [ ] 문구에 포함될 내용:
  - 본 계산 결과는 참고용 추정치이며 실제 신고·납부 세액과 다를 수 있음
  - 정확한 세액은 세무 전문가 또는 관할 세무서에 확인 권고
- [ ] 적용 기준일 명시 (예: "2026년 8월 기준 세법 적용")
- [ ] 근거 법령 표기: 상속세 및 증여세법 제53조(증여재산공제), 제56조(세율), 제69조(신고세액공제)
- [ ] `docs/S-01-research-note.md`에 기록한 국세청 출처 링크 연결
