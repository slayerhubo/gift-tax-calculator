## 등록 방법 A — gh CLI (권장)

```bash
bash scripts/create-issues.sh
```

`gh`가 없다면 먼저 설치:

```bash
winget install --id GitHub.cli
```

설치 후 새 터미널에서 `gh auth login`.

## 등록 방법 B — 웹에서 수동 등록

1. 저장소 → Issues → New issue
2. 위 표의 **제목**을 그대로 복사
3. 해당 `S-0N.md` 파일 내용을 **본문**에 붙여넣기
4. 라벨·마일스톤 지정

## 권장 보드 (Projects)

`Backlog` → `Todo` → `In Progress` → `Done`

**규칙 하나만 지킬 것: `In Progress`에는 항상 카드 1장.**
새 아이디어가 떠오르면 코드를 건드리지 말고 `Backlog`에 이슈만 만들고 넘어간다.
