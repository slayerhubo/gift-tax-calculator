## 1. 증여세 세율 (상증법 제56조)

5단계 초과누진세율. 산출세액 = `과세표준 × 세율 - 누진공제액`

| 과세표준 | 세율 | 누진공제액 |
|---|---|---|
| 1억원 이하 | 10% | — |
| 1억원 초과 ~ 5억원 이하 | 20% | 1,000만원 |
| 5억원 초과 ~ 10억원 이하 | 30% | 6,000만원 |
| 10억원 초과 ~ 30억원 이하 | 40% | 1억 6,000만원 |
| 30억원 초과 | 50% | 4억 6,000만원 |

> 상속세와 동일한 세율표를 사용한다 (상속세 세율 페이지에서 교차 확인함).

## 2. 증여재산공제 (상증법 제53조)

**★ 10년간 합산 한도액이다. 매년 받는 공제가 아니다.**

| 증여자와의 관계 | 공제 한도 (10년) |
|---|---|
| 배우자 | 6억원 |
| 직계존속(부모·조부모) | 5,000만원 |
| └ 수증자가 **미성년자**인 경우 | 2,000만원 |
| 직계비속(자녀·손자녀) | 5,000만원 |
| 기타 친족 (4촌 이내 혈족, 3촌 이내 인척) | 1,000만원 |
| 그 밖의 사람(타인) | 0원 |

> ⚠️ 기타 친족 범위는 국세청 원문 표기(4촌 이내 혈족 / 3촌 이내 인척)를 따랐다.
> 오래된 블로그에는 "6촌 이내 혈족, 4촌 이내 인척"으로 적힌 글이 많으니 그쪽을 믿지 말 것.

## 3. 신고·납부

| 항목 | 값 |
|---|---|
| 신고기한 | 증여일이 속하는 달의 **말일부터 3개월 이내** |
| 신고세액공제 | 기한 내 신고 시 산출세액의 **3%** |

## 4. 세액계산 흐름 (국세청 흐름도 요약)

스프린트 1에서 구현할 **굵은 글씨** 단계만:

**증여재산가액** → 비과세·불산입 차감 → 채무 차감 → 10년 내 동일인 증여재산 가산 → 증여세 과세가액
→ **증여재산공제** 차감 → 감정평가수수료 차감 → **과세표준**
→ **세율 적용(누진공제)** → **산출세액** → 세대생략할증 → **신고세액공제** → 가산세 → **납부할 세액**

MVP는 굵은 글씨만 구현하고, 나머지 단계는 화면에서 "미반영"임을 밝힌다.

## 5. 스프린트 2 이후용 (조사만 해둠, 미검증)

| 항목 | 값 | 상태 |
|---|---|---|
| 무신고 가산세 | 일반 20% / 부정 40% | 국세청 원문 확인 |
| 과소신고 가산세 | 일반 10% / 부정 40% | 국세청 원문 확인 |
| 납부지연 가산세 | 미납세액 × 미납일수 × 0.022% | 국세청 원문 확인 |
| 세대생략 할증 | 30% | 원문 확인, 예외 규정 재확인 필요 |
| 혼인·출산 증여재산공제 | 1억원 | **국세청 원문 미확인 — 사용 전 재확인** |
